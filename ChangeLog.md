# CHANGELOG MMICOMMON FOR [DOLIBARR ERP CRM](https://www.dolibarr.org)

## 1.0

Initial version

Basic helper classes :
* mmi_common : Common useful helpers
* mmi_actions : basic config for actions
* mmi_delayed : for delayed actions when script stops (using __destruct)
* mmi_generic : generic base class with init and loadlang
* mmi_singleton : generic singleton class

## 1.1

New helper classes :
* mmi_prices : helpers to display prices
* mmi_stats : helpers for basic statistics : Median, Quartile, etc.
